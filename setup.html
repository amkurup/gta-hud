Set up "Send to HUD" on iPhone

One-time setup (about 3 minutes). Afterwards: in Apple or Google Maps tap Share → Send to HUD, Bluefy opens with the destination, tap Start.

Before you start

  1. Install Bluefy – Web BLE Browser from the App Store and open this companion once in it: https://amkurup.github.io/gta-hud/

1. Create the shortcut

  1. Open the Shortcuts app → tap + (top right).
  2. Tap the name at the top → Rename → type Send to HUD.
  3. Tap ⓘ at the bottom → turn on Show in Share Sheet → Done.

2. Add 6 actions, in this order

Use the Search Actions bar at the bottom. Each action automatically uses the result of the one above it.

  1. Get URLs from Input
  2. Expand URL
  3. URL Encode
  4. URL Encode (yes, a second one)
  5. Text — tap inside its text box, then:
    a) Copy this text with the button below and paste it into the box:
    bluefy://open?url=https%3A%2F%2Famkurup.github.io%2Fgta-hud%2F%23go%3Fshare%3D
    b) With the cursor at the very end of that text, tap URL Encoded Text in the bar just above the keyboard (it inserts the result of action 4).
  6. Open URLs

Tap Done (top right). That's it.

3. Use it

  1. In Apple Maps or Google Maps, open a place or directions → Share → Send to HUD (scroll the list or tap Edit Actions if you don't see it).
  2. The first time, allow the shortcut to open Bluefy.
  3. Bluefy opens with "Navigate to …" at the bottom → tap Start (pick GTA-HUD if Bluetooth asks).

AirDropped Maps links open in Apple Maps first; share them from there the same way.
