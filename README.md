# GTA HUD web companion

Single-page Web Bluetooth companion for an ESP32 GTA San Andreas-style navigation HUD.
It routes with OSRM, loads roads from OpenStreetMap (Overpass), and streams route, road
tiles and live telemetry to the HUD over BLE. It also works standalone as a HUD simulator.

Open in a Web Bluetooth browser (Chrome/Edge on desktop or Android, Bluefy on iOS):
https://amkurup.github.io/gta-hud/
